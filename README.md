# TypeSpeak — Keyboard Sound & TTS Studio

An interactive web app that combines **mechanical keyboard sound synthesis** with **text-to-speech (TTS)** — built with pure HTML, CSS & JavaScript (Web Audio API + Web Speech API).

## ✨ Features

| Feature | Description |
|---|---|
| ⌨️ Keyboard Sounds | Every keypress triggers a synthesized mechanical click (no sound files needed) |
| 🎹 Visual Keyboard | Full QWERTY keyboard UI that lights up in sync with your typing |
| 🗣️ Text-to-Speech | Press **Enter** to have any typed line/sentence spoken aloud |
| 📜 Spoken History | All spoken lines are logged and can be re-played by clicking |
| 🎵 Voice Controls | Choose voice, adjust speaking speed (0.5x–2x) and pitch |
| 🔊 Sound Toggle | Mute/unmute keyboard click sounds with one click |

## ⌨️ Key Bindings

| Key | Action |
|---|---|
| `Enter` | Speaks the **current line** aloud |
| `Ctrl + Enter` | Inserts a **new line** (no speaking) |
| Any typed key | Plays a **mechanical click** and lights up the key on screen |
| Click on keyboard key | Also triggers sound + inserts character |

## 🛠️ Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Dark glassmorphic design, CSS variables, responsive layout
- **Web Audio API** — Synthesized mechanical keyboard click sounds (no audio files)
- **Web Speech API** — Native browser TTS, no external API needed
